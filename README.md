# Portofolio Minimalis — Bahrudin Yusup Caruban (Zhyusff.Dev)

Website portofolio modern, minimalis, dan responsif yang berfokus pada bidang **Network & Infrastructure Engineer**.

## 🛠️ Teknologi & Fitur
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom CSS Variables (Dukungan Tema Terang & Gelap)
- **Animasi & Interaktivitas**: Framer Motion (Spotlight Cards, Ambient Glow, Card Deck 3D swipe)
- **Asisten AI Terintegrasi**: Chatbot interaktif ramah pengunjung
- **Sentralisasi Data**: Semua konten diatur dalam satu file konfigurasi di `src/config.ts`

## 🚀 Memulai Pengembangan Lokal

1. **Instal Dependensi**:
   ```bash
   npm install
   ```

2. **Jalankan Server Development**:
   ```bash
   npm run dev
   ```
   Buka peramban di [http://localhost:5173/](http://localhost:5173/)

3. **Build Produksi**:
   ```bash
   npm run build
   ```

## ⚙️ Konfigurasi Data Portofolio
Untuk menyesuaikan profil, keahlian, karya, maupun riwayat pendidikan, cukup edit satu file berikut:
`src/config.ts`
